ContextShell

[about]
ContextShell is a lightweight extension for Windows File Explorer that gives
you full control over the right-click context menu. It is a community fork of
Nilesoft Shell (https://github.com/moudey/Shell) with no launcher, no plugin
marketplace and no auto-updater.
Compatible with Windows 10 and Windows 11.

[config]
shell.nss            main config, loaded on every right-click
imports\*.nss        split config files imported by shell.nss
Config syntax is the same as Nilesoft Shell, see the docs folder in the repo.

[update]
(*) If you are updating, please first unregister the previous version:
    shell.exe -unregister -restart
